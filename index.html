LESSON 100–103 完全整理

関係副詞 where・when・why・how と
関係代名詞 which の使い分け

参考書レッスン100〜103の内容をもとに、高校生がいちばんつまずく「where か which か」の判断基準と、5つの頻出ミスを整理しました。最後に確認問題で定着させましょう。

関係副詞の正体 Lesson 100

関係副詞は、正体をたどると「前置詞 + which」です。which だけでは名詞のかたまりにしかなりませんが、前置詞がつくことで「場所で・時に・理由で」という副詞のかたまりになります。

関係副詞正体先行詞の種類書き換え例
wherein / at / on which場所the room where he works = the room in which he works
whenin / on / at which時the day when I saw it = the day on which I saw it
whyfor which理由（reason）the reason why he was late = the reason for which he was late
howin which方法（the way）how he solved it = the way in which he solved it
おさえておきたい前提
関係副詞のうしろは「主語も目的語もそろった完全な文」になります。これは、後ろに「不完全な文（何かが1つ欠けた文）」が続く関係代名詞 which・who・that と正反対の性質です。この違いが、次の章で扱う「where か which か」の判定基準そのものになります。
先に確認しておきたい：そもそも他動詞・自動詞って何？

動詞は大きく2種類に分かれます。

  • 他動詞（transitive verb）：「〜を」にあたる目的語（O）を、前置詞なしでそのまま動詞の直後に置く動詞。目的語がないと文の意味が完成しない。
  • 自動詞（intransitive verb）：それだけで文が成立する動詞。「〜に・〜で・〜へ」のような意味を付け加えたいときは、必ず前置詞を挟む必要がある。

見分け方（かんたんテスト）：動詞の直後に前置詞なしで名詞を置いて意味が通るかどうかを確かめます。

He built the house.（○ built のすぐ後ろに名詞が来る）
→ built は他動詞。the house が目的語。
He lives the house.（✕ 前置詞なしでは置けない）→ He lives in the house.（○）
→ lives は自動詞。the house を続けるには in が必要。

代表的な動詞

他動詞（すぐ後ろに O）よく使う前置詞とセットの自動詞
build ～ / buy ～ / visit ～ / see ～ / make ～ / like ～ / want ～ / meet ～ / watch ～ / take ～live in ～ / work at [for] ～ / arrive at [in] ～ / listen to ～ / wait for ～ / agree with ～ / talk to [about] ～ / go to ～
注意：同じ形で自動詞にも他動詞にもなる動詞がある
例）run：He runs every morning.（自動詞＝走る）／He runs a company.（他動詞＝〜を経営する）
例）stop：The car stopped.（自動詞）／He stopped the car.（他動詞）
このタイプは文ごとに「後ろに前置詞なしの目的語があるか」を必ず確認しましょう。
他動詞・自動詞と「完全文・不完全文」のつながり
「完全文・不完全文」を正しく見抜くカギは、動詞が他動詞か自動詞かを判別できることです。 先行詞が他動詞の目的語としてうしろの文に入る場合 → 目的語がすっぽり抜けた不完全文 → which。
先行詞が自動詞＋前置詞のかたまりで「場所・時・理由」を表す場合 → 動詞だけですでに成立している完全文 → where / when / why。

where と which の見分け方 最重要

「先行詞が場所を表す名詞だから where」と反射的に決めてしまうのが、いちばんよくある誤りです。判断すべきは先行詞の意味ではなく、関係詞のうしろの文が完全文か・不完全文かです。

判定ルール（この手順で必ず判断する）
① 関係詞を消して、先行詞をもとの位置に戻し、1つの文にしてみる。
② その文で、先行詞が動詞の「目的語」や「主語」になっていれば → 文が不完全 → which（関係代名詞）
③ その文で、先行詞が「そこで／そのとき／それが理由で」のように前置詞句として文の外側から意味を添えているだけなら → 文が完全 → where / when / why（関係副詞）
実戦テクニック：先行詞を it に置き換えてみる
頭の中で完全文・不完全文を判断しにくいときは、関係詞が指している場所に、先行詞の代わりに it を置いてみましょう。
  • it がそのまま動詞の直後に置けて、目的語として文が成立する（＝他動詞＋it）→ その位置に目的語が欠けていた＝不完全文 → which
  • it の前に前置詞が必要になる、または there（そこで）に置き換わる（＝自動詞＋前置詞＋it）→ すでに文は完成していた＝完全文 → where / when / why

which（関係代名詞）

This is the house which he built.
戻すと → He built the house.（built は他動詞。the house は built の目的語＝文に不可欠）
→ 目的語が欠けた不完全文なので which。
it テスト：He built it.（it がそのまま目的語になる＝欠けていたのは目的語）→ which

where（関係副詞）

This is the house where he lives.
戻すと → He lives in the house.（lives は自動詞。the house はあくまで「場所」を添える副詞句）
→ すでに完全文なので where。
it テスト：He lives in it. ／ He lives there.（it の前に前置詞が要る＝もともと完全文だった）→ where
This is the room where my father works.
＝ここが私の父が働いている部屋です。（father works in the room → 完全文 → where）
the room＝先行詞（場所）where＝in whichmy father＝Sworks＝V（自動詞）
it テスト：My father works in it.（work は自動詞なので it の前に in が必要）→ where
There is no reason why I must obey him.
＝私が彼に従わねばならない理由はない。（I must obey him for the reason → 完全文 → why）
no reason＝先行詞why＝for whichI＝Smust obey＝Vhim＝O
it テスト：I must obey him for it.（reason には for が必要。him という目的語はすでに埋まっている）→ why
ひっかけ注意：場所の名詞でも which になる例
This is the city which I visited last year.
＝ここが私が去年訪れた都市です。（I visited the city → the city は visited の目的語＝不完全文 → which）
it テスト：I visited it last year.（visit は他動詞なので it がそのまま目的語になる）→ which
the city も「場所」の名詞ですが、visited という他動詞の目的語になっているため which が正解です。先行詞の意味ではなく、うしろの文の完全・不完全で判断する癖をつけましょう。

つまずきポイント5選 Lesson 101–103

参考書のレッスン101〜103に出てくる、テストで狙われやすい5つの落とし穴です。タップして詳しく確認しましょう。

1how と the way はどちらか一方しか使えない▼

how は先行詞を取らない関係副詞です。「the way」と「how」を同時に使うのは誤りで、必ずどちらか片方だけを使います。

This is the way how he became President.
✕ the way と how を同時に使うことはできない。
This is how he became President. ／ This is the way he became President. ／ This is the way in which he became President.
○ how 単独 ／ the way 単独 ／ the way in which（in which を用いる場合は the way を残せる）
2that は when・where・why の代わりになれるが、万能ではない▼

先行詞が the day（時）、the place（場所）、the reason（理由）のような一般的・抽象的な語のとき、when・where・why の代わりに that を使えます。

Is that why you look so happy? ＝ Is that that you look so happy?
＝それが理由であなたはそんなに嬉しそうなのですか。

ただし2つの制限があります。

制限① 前置詞とセットになった形（for which, in which など）は that に置き換えられない。前置詞のすぐ後ろに that を置くことはできない。
制限② コンマを使う非制限用法では that は使えない（次のポイントで詳しく解説）。
3「前置詞＋which＋名詞」というかたまりで先行詞を受ける形がある▼

which 単独ではなく、「前置詞 + which + 名詞」がセットになって、前の文（または語句）全体を先行詞として受けることがあります。in that case（その場合には）のような表現が、そのまま「in which case」の形で関係詞節を作るイメージです。

There may be some words you cannot understand, in which case you can consult a dictionary.
＝理解できない単語があるかもしれないが、その場合は辞書を引けばよい。
in which case＝in that case（その場合には）
She failed the audition for the third time, at which point she gave up becoming an actress.
＝彼女は3度目のオーディションに落ち、その時点で女優になることをあきらめた。
4非制限用法（コンマ付き）で使えるのは where・when・which、that は不可▼

関係副詞・関係代名詞には、先行詞を限定する制限用法（コンマなし）と、情報を補足するだけの非制限用法（コンマあり、「そして～」と訳す）があります。where と when は非制限用法で使えますが、that は非制限用法では使えません。

Boston, where I live, is very cold in winter.
＝ボストンは、（そこに私は住んでいるのだが）冬はとても寒い。
We arrived at the hilltop at noon, when it began to rain.
＝私たちは正午に丘の上に着いたが、その時（＝そしてそのとき）雨が降り出した。
この when は「and then（そしてその時）」に近い、時間の流れをつなぐ非制限用法です。
5That's why ～. と That's because ～. の向きに注意▼

どちらも「原因」と「結果」をつなぐ表現ですが、前後の関係が逆になります。

表現直前の文意味の流れ
That's why ～原因（原因）→ That's why（それが理由で）→ ～（結果）
That's because ～結果（結果）→ That's because（それは～だからだ）→ ～（原因）
Jim got up late. That's why he was late for school.
＝ジムは朝寝坊した。だから学校に遅刻した。（寝坊＝原因 → 遅刻＝結果）
Jim was late for school. That's because he got up late.
＝ジムは学校に遅刻した。それは寝坊したからだ。（遅刻＝結果 → 寝坊＝原因）

リスニング問題 全8問

音声を聞いて、聞こえた関係詞を選びましょう。関係副詞は弱く速く発音されるため、うしろの文が完全か不完全かを耳で判断する練習になります。Level 1（短い2択）→ Level 2（3択・ひっかけ入り）→ Level 3（長文・非制限用法）と少しずつ難しくなります。

音声はブラウザの読み上げ機能を使用します。声が聞き取りにくい・不自然に感じる場合は、下のメニューから別の声を選んでください。音が出ない場合は「スクリプトを表示」を押して、先生が読み上げてください。
